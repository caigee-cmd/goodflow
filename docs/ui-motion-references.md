# Home / Login 动效参考

整理日期：2026-10-14。以下为供曼君确认的参考，不代表已确认或已实现。

## 建议反馈

推荐「轻量、可感知」的动效组合，沿用当前品牌配色和本地产品图片，不改页面结构：

| 页面 | 建议效果 | 参考链接 | 实现判断 |
| --- | --- | --- | --- |
| Home | 案例随滚动轻微上移、淡入；首屏小幅错峰出现，避免一次性大面积移动 | [Motion · Scroll triggered](https://motion.dev/examples/react-scroll-triggered) | 可用现有 Motion 实现；只播放一次，保留卡片占位以免布局跳动 |
| Home | 筛选标签选中标记平滑滑动，案例列表短距离重排 | [Motion · Smooth tabs](https://motion.dev/examples/react-smooth-tabs) | 现有页面已有标签滑块和部分重排；确认后可去掉人为等待的骨架屏，让结果即时过渡 |
| Login | 本地图片缓慢交叉淡化，标题随图片轻微切换；表单始终固定 | [Motion · Carousel autoplay](https://motion.dev/examples/react-carousel-autoplay) | 参考自动切换节奏，交叉淡化和标题同步是本项目拟采用的变体；现有 CSS 已有淡化和慢速缩放，可在此基础上优化，无需 WebGL |

这些链接是可运行的交互示例，参考的是动作和节奏，不复用示例配色或整页视觉。部分示例完整源码需 Motion+，实现上述基础效果不需要购买源码。

## 与收藏入口的关系

收藏同时包含 Cases 和 Products，应作为全局个人操作：放在顶栏右侧、Ask 左侧，以心形图标、数量角标和 Favorites 悬停提示呈现，不挂在首页 Details 标题下。本轮已完成位置调整。

## 确认后再实现

- Home 首屏入场建议 300–450ms，卡片错峰不超过 60ms；悬停仅微缩放或轻微抬升。
- Login 图片停留建议 7–9 秒，交叉淡化约 800–1200ms；不移动输入框，不延迟登录操作。
- 使用 `prefers-reduced-motion` 降级；不增加新的动效依赖，不影响现有图片查看、搜索和筛选。
- 桌面演示检查 1366×768、1920×1080，并检查低性能设备上的滚动流畅度。
